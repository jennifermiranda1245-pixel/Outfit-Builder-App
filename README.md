# Outfit-Builder-App
My app is an outfit builder that helps you create outfits from clothing items that you already have in your closet and you can also add pictures. You ca categorize them by season like winter, summer, spring, and fall and you can choose a specific season to create outfits just from the selected season. I used ChatGPT to help create my app. My main focus was the main layout of the outfit view would look like I initially wanted to make it look like in Pinterest and you would scroll through different premade outfits but I struggled with that because it would take over the whole screen and I felt like the AI didn't understand what I wanted so I just decided to keep the initial code that I had gotten and keep it in like a card view instead. Overall I am happy with how my app ended up looking I think it is easy to navigate and understand and I see myself using something like this to help me create outfits.
